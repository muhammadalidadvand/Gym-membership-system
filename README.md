Gym Membership System

A beginner-level Python project for registering gym members and calculating membership fees based on eligibility and discount conditions.

About the Project

Gym Membership System is a simple command-line application developed using Python.

The program allows an operator to register multiple gym members, check their age eligibility, calculate membership fees, and apply discounts based on student and returning-member status.

Member information is stored in a list of dictionaries during program execution.

Features

- Register multiple gym members in one execution.
- Check minimum age eligibility (18+).
- Apply student discounts (20%).
- Apply returning-member discounts (10%).
- Apply combined discounts (30%).
- Store registered members using a list of dictionaries.
- Display individual member information.
- Display all registered members at the end of execution.

Discount System

Membership Type| Discount
Regular Member| 0%
Student| 20%
Returning Member| 10%
Student + Returning Member| 30%

Base Membership Fee: 500,000

How to Run

1. Make sure Python 3 is installed.
2. Download this repository.
3. Open a terminal in the project directory.
4. Run the following command:

python main.py

Current Limitations

- Member information is stored temporarily in memory.
- Registered data is not saved after the program closes.
